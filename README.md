# Chatter

Chatter is a responsive landing page for a text-based blogging and reading platform. It introduces the platform, highlights key features, shares a user testimonial, and encourages visitors to join.

## Features

- Responsive navigation and hero section
- Platform overview and feature cards
- User testimonial
- Call-to-action section
- Footer with exploration and support links
- Tablet and mobile layouts

## Technologies

- HTML5
- CSS3
- Google Fonts (DM Sans)

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

For the best development experience, use the Live Server extension in VS Code:

1. Install the Live Server extension.
2. Open `index.html`.
3. Click **Go Live**.

The site will be available at a local address such as `http://127.0.0.1:5500`.

## Customization

- Update page content and links in `index.html`.
- Update colors, spacing, typography, and responsive rules in `styles.css`.
- Replace or add images in the `images/` directory.
